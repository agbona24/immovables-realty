# IMMOVABLES REALTY Website

A stunning, professional real estate website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- ✨ Beautiful, modern UI/UX design
- 🎨 Brand-consistent styling following IMMOVABLES REALTY brand guidelines
- 🎭 Smooth animations and transitions powered by Framer Motion
- 📱 Fully responsive design for all devices
- ⚡ Fast and optimized with Next.js 16
- 🎯 SEO-friendly structure
- 💼 Professional sections:
  - Hero section with dynamic animations
  - About/Services showcase
  - Featured properties with interactive cards
  - Why Choose Us with animated statistics
  - Contact form with validation
  - Professional footer

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** Google Fonts (Montserrat, Poppins, Allura)

## Getting Started

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Build

```bash
npm run build
```

### Production

```bash
npm start
```
